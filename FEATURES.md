## Key Features

- Real-time telemetry simulation with configurable drift and anomaly injection
- Three ML models: Isolation Forest, XGBoost, Logistic Regression
- PSI-based drift detection with STABLE / DEGRADED / DRIFTING status
- Ollama LLM executive narrative generation with rule-based fallback
- JWT authentication with read-only access for unauthenticated users
- PDF executive report export
- CSV baseline upload and model retraining via dashboard
- Auto-refresh dashboard every 5 seconds
